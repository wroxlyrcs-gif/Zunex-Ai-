# Zunex AI Native

Native Android version of Zunex AI.

## Technology
- Kotlin
- Jetpack Compose
- Room Database

## Requirements
- Preserve the original web application.
- Keep all existing features and knowledge.
- Support Azerbaijani, Turkish, English and Russian.
- Support offline functionality.
- Provide safe JSON import and export.
- Do not overwrite or delete original user data.

## Important
This project is developed separately from the original web application.
